# Estrutura de Dados em Java

Este repositório reúne implementações **didáticas e práticas de Estruturas de Dados utilizando a linguagem Java**, com foco no aprendizado acadêmico e no fortalecimento da lógica de programação.  

O projeto é voltado para estudantes de cursos de Computação, Sistemas de Informação, Engenharia de Software e áreas afins.

---

## 🎯 Objetivos do Repositório

- Compreender o funcionamento interno das principais estruturas de dados
- Aplicar conceitos fundamentais de **Programação Orientada a Objetos (POO)** em Java
- Desenvolver raciocínio lógico e habilidades de resolução de problemas
- Servir como material de apoio para a disciplina de **Estrutura de Dados**

---

## 🧱 Estruturas de Dados Abordadas

O repositório pode conter implementações como:

- Vetores e Arrays
- Listas Lineares  
  - Lista Sequencial  
  - Lista Encadeada  
- Pilhas (Stack)
- Filas (Queue)
- Árvores (ex: Árvore Binária)
- Algoritmos auxiliares (busca, inserção, remoção, etc.)

> ⚠️ As estruturas podem estar organizadas em pacotes distintos conforme o conteúdo estudado.

---

## 🛠️ Tecnologias Utilizadas

- **Java** (JDK 8 ou superior)
- IDE recomendada:
  - IntelliJ IDEA
  - Eclipse
  - VS Code (com extensão Java)
